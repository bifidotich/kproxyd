# kproxyd

Демон для роутеров Keenetic с Entware: проверяет VPN-туннели, уже настроенные в Keenetic,
и для каждой группы держит SOCKS5-прокси, который ведёт трафик через живой и быстрый туннель.
Конфигурацию Keenetic kproxyd только читает и ничего в ней не меняет.

```
устройство → Keenetic (список доменов → Proxy0) → SOCKS5 kproxyd → активный туннель → интернет
```

## Установка и обновление

Нужны Entware и `curl` (`opkg update && opkg install curl ca-bundle`). На роутере по SSH:

```sh
curl -fsSL https://github.com/bifidotich/kproxyd/releases/download/latest/install.sh | sh
```

Скрипт сам определит архитектуру (mipsel, mips, aarch64), скачает сборку, сверит контрольные
суммы и запустит службу. Той же командой делается обновление — конфиг сохраняется.
Конкретная версия: `... | sh -s -- v0.2.0`.

Релиз `latest` пересобирается при каждом пуше в `main`, метки `v*` дают неизменяемые релизы.

## Настройка

1. Откройте веб-интерфейс `http://<роутер>:8088/` (логин и пароль покажет установщик).
2. Добавьте выходы — VPN-подключения Keenetic (`Wireguard0`, `OpenVPN0`…).
3. Создайте группу с адресом SOCKS5, например `127.0.0.1:1081`.
4. В Keenetic установите компонент «Клиент прокси», создайте прокси-подключение SOCKS5 на этот
   адрес и направьте в него списки доменов. Готовые команды — в карточке группы.

## Удаление

```sh
sh /opt/sbin/kproxyd-uninstall            # конфиг останется
sh /opt/sbin/kproxyd-uninstall --purge    # вместе с конфигом
```

Прокси-подключение и маршруты в Keenetic убираются вручную.

## Сборка из исходников

```sh
./build.sh              # dist/kproxyd-{mipsel,mips,aarch64}, нужен Go 1.22+
sh scripts/install.sh   # на роутере, из папки проекта — поставит локальную сборку
```
